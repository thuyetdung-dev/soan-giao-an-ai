LESSONSTUDIO V8.5 — MATHVIZ HTML STUDIO

XƯỞNG ẢNH → HTML
1. Chạy offline, không cần Gemini API.
2. Tải PNG, JPG/JPEG hoặc WEBP và chuyển thành thẻ figure/img nhúng data URI.
3. Tùy chỉnh alt text, chú thích và chiều rộng tối đa.
4. Xem trước trực tiếp, sao chép thẻ HTML và tải trang HTML độc lập.
5. Dựng đồ thị hàm số từ biểu thức an toàn rồi chuyển thành HTML.
6. Tự dựng bảng biến thiên và xuất bảng HTML có mũi tên tăng/giảm.
7. Nhận graph hoặc variation_table JSON của LessonStudio và chuyển thành visual HTML.
8. Escape alt text, caption và nội dung bảng để tránh chèn mã HTML ngoài ý muốn.
9. Trang HTML có UTF-8, responsive và hoạt động độc lập không cần mạng.

CÁCH DÙNG
- Chọn “🖼️ Xưởng Ảnh → HTML” trong Chế độ làm việc.
- Chọn tab Nhúng ảnh, Đồ thị hàm số, Bảng biến thiên hoặc JSON → visual.
- Dùng biểu tượng sao chép trên khung mã hoặc bấm TẢI HTML.
